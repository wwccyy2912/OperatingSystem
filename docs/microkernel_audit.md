# 微内核化审计报告（Microkernel Audit）

> 目标：**高性能关键与安全关键逻辑保留内核，可服务化的迁出用户态**。
> 审计基准：`ed9f082` 之后的 kernel/（约 1.43 万行）。
> 原则：迁出用户态的前提是——不牺牲性能、不降低隔离安全性、不增加关键路径
> 上下文切换；反之（性能关键、安全关键、硬件特权依赖）必须留内核。

## 一、子系统逐项结论

| 子系统 | 位置 | 行数 | 结论 | 理由 |
|---|---|---|---|---|
| 进程/线程/调度 | kernel/sched, kernel/process | 1931 | **留内核** | 调度与上下文切换是性能与安全核心；用户态无法管理特权态切换 |
| 物理/虚拟内存 | kernel/mm | 2146 | **留内核** | 页表操作需特权级；内存分配是全局资源，用户态无法隔离 |
| 能力系统 (cap) | kernel/cap | 550 | **留内核** | 安全模型核心：权限检查不可信用户态 |
| IPC/信号/互斥 | kernel/ipc | 1194 | **留内核** | 内核同步原语；用户态互斥走内核（无 futex 类共享内存同步） |
| syscall 层 | kernel/syscall | 2412 | **留内核** | 系统调用边界本身 |
| GDT/IDT/中断 | kernel/arch/x86_64 | 2340 | **留内核** | 特权指令；IDT 只能内核写 |
| 帧缓冲 (fb) | kernel/gfx | 184 | **留内核** | 只做映射/模式查询（SYS_FB_GET_INFO/MAP）；渲染全在用户态 term/gui |
| 串口/时钟/RNG 初始化 | kernel/arch/x86_64 (serial/rtc/rng) | ~600 | **留内核** | 早期启动日志/时钟源；驱动服务（keyboard/serial 用户态）已在用户态 |

| blob 镜像管理 | kernel/blob | 147 | **留内核** | 与进程创建耦合，用户态无法验证 ELF 加载 |
| panic | kernel/panic.c | 344 | **留内核** | 崩溃处理必须在内核 |

## 二、迁移候选

### 候选②：virtio-blk 块设备驱动（627 行）
- **现状**：内核内 virtio_blk.c 直接操作 PCI BAR 与 MMIO 队列，用户态
  vfs 磁盘驱动（fs_virtio_blk_driver.c，用户态）通过
  `sys_blk_read/write/info` 系统调用间接访问。
- **留内核理由**：磁盘 I/O 走 DMA（virtio 描述符环由驱动维护），中断
  处理与页缓冲管理都在内核；迁到用户态需要把 DMA/中断路径全部下沉，
  收益（少一次 syscall 往返）远小于风险（用户态驱动崩溃破坏磁盘）。
- **结论：保持现状**（驱动在内核、策略在用户态，已是合理的微内核分层）。

### 其余候选评估
- **fb 渲染**：已在用户态（term/gui 服务），内核只保留映射 ✓。
- **键盘/串口驱动**：已在用户态（keyboard/serial 服务），内核只提供
  I/O 端口/IRQ 能力 ✓。
- **网络协议栈**：已在用户态（net 服务）✓。
- **VFS/文件系统**：已在用户态（vfs 服务 + 驱动）✓。
- **窗口合成/终端**：已在用户态（gui/term/wm 服务）✓。

## 三、结论

当前内核已经是**功能型微内核（pragmatic microkernel）分层**：
- 内核：调度、内存、cap、IPC、中断、驱动（blk/PCI/fb 硬件访问）、syscall。
- 用户态服务：serial/keyboard/term/vfs/net/gui/wm/shell/init 全部独立进程，
  通过 IPC + 能力授权交互，互不共享地址空间。

无必须迁出的内核模块——剩余的"可迁移项"（virtio-blk）迁出风险大于收益。
后续若引入用户态 DMA 框架（如 usercopy + 用户态描述符环 + 中断转发），
可再评估 blk 驱动下沉，但当前架构与"高性能微内核"目标一致。

## 四、性能关键路径核对（留内核的正确性）

| 路径 | 当前层 | 是否最优 |
|---|---|---|
| 系统调用分发 | 内核（O(1) 表查 + 能力检查） | ✓ |
| 线程切换 | 内核（直接上下文切换，无用户态往返） | ✓ |
| 页分配/映射 | 内核（无页表锁竞争的用户态代理） | ✓ |
| IPC 调用-应答 | 内核（等待队列 + 直接唤醒，无中间层） | ✓ |
| 磁盘 DMA | 内核（描述符环 + 中断处理直连） | ✓ |
| 终端/网络渲染 | 用户态（计算密集，不占内核） | ✓（卸载内核负载） |
